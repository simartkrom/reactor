## 도구별 최적 활용 전략

### Kling — 인물 중심 샷
- **강점**: 인물 표정 변화, 감정 연기, 소규모 동작
- **최적 샷**: 클로즈업, 미디엄 샷, 대화 씬
- **팁**: Image-to-Video에서 인물 얼굴을 선명하게 넣을수록 일관성 ↑
- **적합 씬**: S#3 팀장 대화, S#6 전화 씬, S#9 옥상 대화

### Veo — 풍경/무드 샷
- **강점**: 시네마틱 풍경, 분위기 있는 조명, 자연스러운 카메라 움직임
- **최적 샷**: 와이드 샷, 이스타블리싱 샷, 분위기 전환
- **팁**: 조명/시간대 묘사를 구체적으로 (golden hour, neon-lit night 등)
- **적합 씬**: S#1 서울 아침, S#8 옥상 석양, S#13 엔딩 거리

### Sora — 복잡한 움직임
- **강점**: 카메라 무빙, 복잡한 시퀀스, 롱테이크 느낌
- **최적 샷**: 트래킹 샷, 돌리 인/아웃, 크레인 샷
- **팁**: 카메라 움직임을 명시적으로 지시 ("camera slowly pushes in")
- **적합 씬**: S#2 출근길 트래킹, S#10-11 작업 몽타주

### Grok — 실험/보조
- **강점**: 빠른 생성, 변형 실험
- **용도**: 대안 샷 시도, 컨셉 테스트, 빈 구간 채우기

## 캐릭터 일관성 유지 전략 (가장 중요)

AI 영상 제작에서 **제일 어려운 것이 캐릭터 일관성**입니다.

### 방법 1: 레퍼런스 이미지 고정
1. NanoBanana Pro에서 캐릭터별 정면/측면/반측면 이미지 확정
2. 모든 키프레임 생성 시 동일 레퍼런스를 seed로 사용
3. 프롬프트에 외모 묘사를 **매번 동일하게** 복붙

### 방법 2: 의상으로 통일감
- 지우: **항상 같은 옷** (이 영화는 하루+아침이니까 자연스러움)
  - 낮: 베이지 니트 + 검은 슬랙스 + 안경
  - 밤 작업: 같은 옷 (소매 걷음)
  - 다음 날 아침: 후드집업 추가
- 도현: 검은 터틀넥 + 청바지 (고정)

### 방법 3: 얼굴 리스크 관리
- 클로즈업은 최소화 (일관성 깨지기 쉬움)
- 감정 표현이 필요한 샷 → 뒷모습, 손, 실루엣으로 대체 가능
- 정면 클로즈업은 키프레임을 매우 정밀하게 생성

## 프롬프트 작성 규칙

### NanoBanana Pro (키프레임 이미지)
```
[스타일] cinematic, photorealistic, film grain, 35mm
[조명] 구체적 조명 상태 (예: soft morning light, harsh fluorescent)
[구도] 샷 타입 (예: medium close-up, wide shot, over-the-shoulder)
[인물] 캐릭터 외모 고정 묘사 (매번 동일하게)
[행동] 현재 포즈/표정
[배경] 장소 묘사
[분위기] 감정 키워드
```

### 영상 생성 (Kling/Veo/Sora/Grok)
```
[키프레임 이미지] +
[모션 지시] 무엇이 어떻게 움직이는지 (예: "woman slowly turns head to right")
[카메라] 카메라 움직임 (예: "camera slowly pushes in", "static shot")
[분위기] 톤/무드
[시간] 지속 시간 (보통 5초)
```
