# Project Guidelines

## SkillsMP Search - Skill Installation Security Guidelines

When installing skills discovered through the SkillsMP search skill, the following guidelines **must** be strictly followed:

1. **Security Review in Isolated Environment**
   - Before installing any specific skill, conduct a security review in a risk-free isolated folder first
   - Report the security review results to the user before proceeding

2. **User Approval Required**
   - After presenting the security review results from step 1, **always** obtain explicit user approval before installing any skill
   - Do not proceed with installation without clear user consent

3. **Caution for New or Low-Star Skills**
   - If a skill is newly published or has a low star rating, **do not install it**
   - Notify the user about the potential security risks and advise caution
   - Let the user make an informed decision about whether to proceed
