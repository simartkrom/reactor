# 영화 시나리오 작성 가이드

## 1. 시나리오 기본 포맷

영화 시나리오는 업계 표준 포맷을 따릅니다. 한국 영화계에서도 할리우드 표준 포맷을 기반으로 하되, 한국어 특성에 맞게 조정합니다.

### 핵심 구성 요소

| 요소 | 설명 | 예시 |
|------|------|------|
| **씬 헤딩 (Scene Heading)** | 장소, 시간 표시 | `#1. 서울 도심 - 아파트 옥상 (낮)` |
| **지문 (Action/Description)** | 장면 묘사, 행동 설명 | 카메라에 보이는 것만 서술 |
| **대사 (Dialogue)** | 캐릭터의 말 | 캐릭터명 아래 대사 |
| **괄호 지시 (Parenthetical)** | 대사 톤/행동 지시 | `(속삭이며)`, `(웃으며)` |
| **전환 (Transition)** | 장면 전환 | `컷 투(CUT TO):`, `디졸브(DISSOLVE):` |
| **V.O. / O.S.** | 보이스오버 / 화면 밖 소리 | `민수 (V.O.)`, `영희 (O.S.)` |

### 씬 헤딩 작성법

```
#씬번호. 장소 - 세부장소 (시간)
```

- **장소 구분**: 실내(INT.) / 실외(EXT.) / 실내외(INT./EXT.)
- **시간 구분**: 낮 / 밤 / 새벽 / 저녁 / 해질녘
- **예시**: `#1. INT. 서울 강남 - 고급 레스토랑 (밤)`

### 지문 작성 원칙

1. **현재형**으로 작성 (과거형 X)
2. **카메라에 보이는 것**만 서술
3. **감정/생각 직접 서술 금지** → 행동과 표정으로 표현
4. **간결하게** — 한 문단 4-5줄 이내

```
❌ 민수는 슬펐다. 그는 과거를 떠올리며 후회했다.
✅ 민수, 창밖을 바라본다. 손에 든 사진을 꼭 쥔다. 턱이 미세하게 떨린다.
```

### 대사 작성 원칙

1. **캐릭터별 말투** 차별화 (나이, 성격, 직업 반영)
2. **서브텍스트** 활용 — 직접 말하지 않고 에둘러 표현
3. **간결하게** — 영화 대사는 짧을수록 좋음
4. **설명 대사 지양** — "우리가 10년 전 여기서..." 식의 억지 설명 피하기

```
❌ 영희: 나는 너를 사랑하지만 너의 거짓말 때문에 신뢰를 잃었어.
✅ 영희: (찻잔을 내려놓으며) ...커피 식었다.
```

## 2. 3막 구조 (Three-Act Structure)

영화 시나리오의 가장 기본적인 뼈대입니다.

### 제1막: 설정 (Setup) — 전체의 약 25%

- **일상 세계**: 주인공의 평범한 일상
- **촉발 사건 (Inciting Incident)**: 일상을 깨뜨리는 사건
- **1차 전환점 (First Turning Point)**: 주인공이 새로운 세계로 진입

### 제2막: 대립 (Confrontation) — 전체의 약 50%

- **상승하는 갈등**: 점점 커지는 장애물
- **중간점 (Midpoint)**: 판도가 뒤집히는 결정적 순간
- **위기 (Crisis)**: 최악의 상황, 모든 것을 잃는 순간
- **2차 전환점 (Second Turning Point)**: 최후의 결전을 향한 결심

### 제3막: 해결 (Resolution) — 전체의 약 25%

- **클라이맥스 (Climax)**: 최종 대결
- **결말 (Denouement)**: 새로운 일상, 변화된 주인공

### 시간 배분 (120분 기준)


## 3. 캐릭터 설계

### 캐릭터 프로필 필수 항목

| 항목 | 설명 |
|------|------|
| **이름/나이** | 기본 정보 |
| **외적 목표 (Want)** | 캐릭터가 의식적으로 추구하는 것 |
| **내적 욕구 (Need)** | 캐릭터가 진정으로 필요한 것 (본인은 모름) |
| **결함 (Flaw)** | 내적 욕구를 방해하는 성격적 결함 |
| **배경 (Backstory)** | 결함이 형성된 과거 사건 |
| **아크 (Arc)** | 결함 → 깨달음 → 변화의 여정 |

### 캐릭터 관계도

- **주인공 (Protagonist)**: 이야기를 이끄는 인물
- **적대자 (Antagonist)**: 주인공의 목표를 방해하는 힘
- **조력자 (Ally)**: 주인공을 돕는 인물
- **멘토 (Mentor)**: 지혜를 전하는 인물
- **수호자 (Guardian)**: 문턱을 지키는 인물

## 5. 시나리오 분량 기준

- **1페이지 ≈ 1분** (업계 관행)
- **장편 영화**: 90~120페이지
- **단편 영화**: 5~30페이지
- **한 씬 평균**: 1~3페이지

---

## 6. 자주 쓰이는 기법

### 서브텍스트 (Subtext)
대사 뒤에 숨겨진 진짜 의미. 캐릭터는 자기 감정을 직접 말하지 않는다.

### 식물 회수 (Plant & Payoff)
초반에 심어둔 단서(Plant)가 후반에 의미를 갖는 것(Payoff).

### 극적 아이러니 (Dramatic Irony)
관객은 알지만 캐릭터는 모르는 정보.

### 시각적 스토리텔링 (Visual Storytelling)
대사 없이 이미지만으로 이야기를 전달.

### 틱킹 클록 (Ticking Clock)
시간 제한을 두어 긴장감 극대화.
