# Awesome Projects Reference Skill

## When to Use

Activate this skill when users:
- Ask for library or framework recommendations ("React 상태관리 뭐가 좋아?")
- Need architecture or best practice references
- Want to explore a technology stack or compare options
- Ask for learning resources, free books, or courses
- Need to find popular open-source tools for a specific domain

## Response Guidelines

1. Identify the user's domain from their question
2. Reference the matching awesome list from the table above
3. Recommend checking Stars count (1K+ preferred) and recent activity (6 months)
4. Provide direct GitHub links for exploration
5. For stack decisions, compare 2-3 options from relevant lists with pros/cons
